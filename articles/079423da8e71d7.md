## 1. 公約をコードにできないか？

政治家の公約は自然言語で書かれ、PDFで配布され、選挙が終わると静かに忘れられます。

「言った言わない」が成立するのは、約束が曖昧な形式で残されているからです。コードであれば、そうはいきません。バージョン履歴は消えないし、差分は明示されます。

公約を宣言的に書き、現実データと定期的に照合する。それだけで、政治の透明性は大きく変わります。

---

## 2. YAMLでの具体例

```yaml
policy:
  title: 最低賃金の引き上げ
  target:
    metric: minimum_wage_jpy_per_hour
    value: 1500
    deadline: "2025-12-31"
  status: commit
```

`status: commit` にした瞬間、記録に刻まれます。

あとはCIのように定期チェックを走らせるだけです。

```bash
$ pac check

[PASS] 最低賃金: 目標 1500円 / 現状 1500円 ✓
[FAIL] 待機児童数: 目標 0人 / 現状 2,567人 ✗
```

公約が果たされていなければ、CIが落ちます。

## 3. 分散型のリポジトリで保存する必要性

政治的な記録をオープンにしようとする取り組みはすでに存在します。GitHubでテキストを管理するアプローチ、Webアプリで市民参加を促すアプローチ。いずれも透明性という意味では一歩前進です。

しかし、どちらも同じ問題を抱えています。**単一の管理者が存在する中央集権**であることです。

運営が削除すれば消え、改ざんされる可能性があり、政府からの圧力があれば非公開にされる可能性もあります。そして法的な拘束力もありません。

公約の記録が本当に意味を持つためには、**誰も書き換えられず、誰も消せない場所**に置く必要があります。それがブロックチェーンを使う理由です。

この問題意識から、私はGoでCivilChainを開発しています。法律・公約・政治的な記録を改ざん不可能な形で残すことを目的としたプロジェクトです。
